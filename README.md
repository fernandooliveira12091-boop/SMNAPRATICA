# Manual do Salário-Maternidade na Prática — Landing Page

Página única e autocontida (`index.html`), pronta para GitHub Pages.

## Configuração
No fim do `index.html`, edite o bloco `const CONFIG`:
- `preco`: valor exibido na página
- `checkoutUrl`: link de checkout (ex.: Hubla). Se vazio, o botão abre o WhatsApp
- `whatsapp`: número com DDI + DDD, sem espaços

## Publicação (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)`.
